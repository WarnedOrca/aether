# Made-up sample pilot files (NOT real data)

Everything in this folder is invented to test `scripts/pilot_report.py`. `FAKE-A` and `FAKE-B` are not businesses, and none of the numbers describe anyone. Never copy them into `private/pilot-log.csv`, a paper, an application or any public page.

- `pilot-log.csv`: same columns as `private/pilot-log.csv`.
- `logs/<business code>/draft-pack-audit-*.csv`: audit logs as downloaded from `tool/draft-pack.html`.
- `logs/<business code>/draft-pack-timing-*.csv`: stopwatch rows as downloaded from the page.
