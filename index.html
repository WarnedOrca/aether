Aether

A small language for business procedures. A checker enforces the policy's rules before anything runs.

This page runs only Aether's checker and interpreter, as Python inside your browser (via Pyodide). Everything uses mock data, and nothing you type is sent anywhere. The fine-tuned model is not hosted here; to generate programs from English, run it locally (see the code repository) or download the adapter from Hugging Face.
